# KNOWME — Personal MERN Stack Portfolio

![KNOWME Banner](./client/public/portfolio.png) 

**KNOWME** is a fully responsive, modern, animated developer portfolio built using the **MERN stack**. It showcases my projects, skills, and personality while offering an engaging user experience with animations, secure authentication, and a custom admin panel.

---

## 🔗 Live Demo

➡️ [Visit Portfolio](https://my-portfolio-end-to-end-with-mern-1.onrender.com)

---

## 🚀 Tech Stack

- **Frontend:** React, Tailwind CSS, Framer Motion, Shadcn, React Intersection Observer
- **Backend:** Node.js, Express.js, MongoDB
- **Email:** Nodemailer
- **Authentication:** JWT, OTP Verification
- **Deployment:** Render

---

## ✨ Features

- ✅ **Home Page** — Landing area with animations and project highlights
- ✅ **Email Verification System** — OTP sent via email, followed by a welcome email after verification
- ✅ **Authentication** — Register/Login with proper feedback and email verification
- ✅ **Admin Panel** — Add, update, and manage projects, skills and contacts dynamically
- ✅ **Skills Section** — Interactive, animated skill roadmap with hover effects and progress
- ✅ **Project Carousel** — Showcases projects with multiple images
- ✅ **Error Handling**:
  - 404 Page with navigation
  - Error messages for backend/API issues
  - Placeholder for upcoming blog feature
- ✅ **Avatar Toggle** — Click to switch between two professional-looking avatars (PNG)
- ✅ **Framer Motion + TailwindCSS** — Smooth animations and responsive layout
- ✅ **Mobile Friendly** — Fully responsive across all screen sizes
- 🚧 **Blog Section** — Under development using **Next.js** and will be integrated soon

## 🛠️ Installation & Setup

Clone the project and run both client and server:

```bash
# Clone the repo
git clone https://github.com/ADNUKUNHOME/MY-PORTFOLIO-end-to-end-with-mern.git
cd my-portfolio

# Install server dependencies
cd server
npm install

# Install client dependencies
cd ../client
npm install

# Start both (you can use concurrently or separate terminals)
npm run dev
